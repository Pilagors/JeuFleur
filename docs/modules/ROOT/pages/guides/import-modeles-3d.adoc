= Importer un modèle 3D

== Préparer le modèle dans Blender

* Échelle : 1 unité Blender = 1 mètre dans Godot.
* Appliquer les transformations avant l'export (*Ctrl+A → All Transforms*), sinon l'échelle et la rotation arrivent faussées.
* Exporter en *glTF binaire (`.glb`)*, le format conseillé. Le `.blend` source peut aussi être versionné (il est en LFS).

== Ajouter le fichier au projet

. Copier le `.glb` dans `assets/models/` (un sous-dossier par catégorie si besoin).
. Revenir dans Godot : il importe le fichier automatiquement et crée un `.glb.import` à côté.
. Commiter le `.glb` *et* son `.import`. Le `.glb` passe automatiquement par Git LFS.

== Choisir le corps physique

[cols="2,2,3"]
|===
| Type d'objet | Corps | Exemples

| Objet qui subit la physique (tombe, se pousse, se ramasse)
| `RigidBody3D`
| Items, caisses, boîte noire

| Objet fixe avec collision
| `StaticBody3D`
| Murs, sols, consoles, portes de module

| Personnage contrôlé par du code
| `CharacterBody3D`
| Joueur, monstres

| Décor sans collision
| Pas de corps, juste le `MeshInstance3D`
| Câbles, petits détails, lumières décoratives
|===

Selon xref:architecture.adoc[], la racine de la scène d'une entité est le corps lui-même, et le modèle importé est instancié en enfant :

----
Item (RigidBody3D)          ← racine, script item.gd
├── Model (instance du .glb)
└── CollisionShape3D
----

Penser à régler les couches de collision du corps (`world`, `player`, `item`, `monster`, `interactable`, voir xref:architecture.adoc#_input_map_et_couches_de_collision[Architecture]).

== Générer la collision

=== Depuis un MeshInstance3D

. Sélectionner le `MeshInstance3D` dans la scène.
. Menu *Mesh* (en haut de la vue 3D) → *Create Collision Shape…*
. Placement *Sibling* (la forme est créée à côté du mesh, sous le corps).
. Type selon le corps :
+
[cols="1,3"]
|===
| Type | Quand l'utiliser

| *Single Convex*
| `RigidBody3D` et `CharacterBody3D` : une seule forme convexe, rapide.

| *Multiple Convex*
| Objet mobile de forme creuse ou en L, quand une seule forme convexe est trop grossière.

| *Trimesh*
| `StaticBody3D` uniquement : collision exacte, mais lente et interdite sur un corps qui bouge.
|===

Pour un objet simple, une forme primitive (`BoxShape3D`, `CapsuleShape3D`, `SphereShape3D`) ajoutée à la main est encore plus légère.

=== Depuis la fenêtre d'import

Double-cliquer sur le `.glb` dans le dock FileSystem ouvre *Advanced Import Settings*.
Sur un mesh, la section *Physics* permet de cocher *Generate*, puis de choisir le *Body Type* (Static, Dynamic, Area) et le *Shape Type*.
Cliquer sur *Reimport* pour appliquer. Ces réglages sont enregistrés dans le `.import`, d'où l'importance de le commiter.

== Attacher un objet à un os

Pour suivre une partie animée du modèle (la caméra sur la tête du joueur, un objet dans la main) :

. Ouvrir le `.glb` en scène héritée (*clic droit → New Inherited Scene*) ou passer l'instance en *Editable Children*.
. Ajouter un `BoneAttachment3D` en enfant du `Skeleton3D`, et choisir l'os dans *Bone Name*.
. Placer la caméra (ou l'objet) en enfant du `BoneAttachment3D`.
