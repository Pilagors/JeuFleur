== Ajouter une page

. Copier `docs/modules/ROOT/examples/modele-fonctionnalite.adoc` vers `docs/modules/ROOT/pages/fonctionnalites/<nom>.adoc`.
. La remplir, puis l'ajouter dans la liste ci-dessus et dans `docs/modules/ROOT/nav.adoc`.
. La commiter avec le code de la fonctionnalité, dans le même commit.

Pour les liens vers le code, utiliser l'attribut `\{url-code}`, qui pointe vers la branche `main` sur GitHub :

[source,asciidoc]
----
\{url-code}/entities/player/player.gd[player.gd]
----
